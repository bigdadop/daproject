# E-Commerce Product Recommendation Analytics Project

## Overview
This project analyzes e-commerce data to create a product recommendation system and interactive dashboard for visualizing user behavior and product trends.

## Project Structure
```
├── data/               # Data directory for storing datasets
├── notebooks/         # Jupyter notebooks for analysis
├── src/              # Source code
├── requirements.txt  # Project dependencies
└── README.md        # Project documentation
```

## Features
- Data cleaning and preprocessing
- Missing value handling
- Feature engineering
- Exploratory Data Analysis (EDA)
- Interactive dashboard
- Product recommendation system
- Outlier detection and handling

## Technology Stack
- Python 3.8+
- Pandas for data manipulation
- NumPy for numerical operations
- Scikit-learn for machine learning
- Plotly and Dash for interactive dashboard
- Jupyter Notebook for analysis
- Matplotlib and Seaborn for visualization

## Dataset
The project uses an e-commerce dataset from Kaggle containing:
- User behavior data
- Product information
- Transaction history
- User demographics
- Rating and reviews

## Setup Instructions
1. Clone the repository
2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
3. Run Jupyter Notebook:
   ```
   jupyter notebook
   ```
4. Launch the dashboard:
   ```
   python src/dashboard.py
   ```
